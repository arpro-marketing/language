Rules

  • Orange is an accent, not a canvas. Buttons, bars, key numbers, accent phrases. Never body text, never a large background.
  • Small orange text on light backgrounds uses 700 (#C4430F). On dark sections, small orange text uses 500.
  • Buttons: logo orange with white 19px bold labels. Hover goes darker (600), pressed goes to 800. No glow shadow.
  • Punctuation takes its word's color, as before.
  • Depth: flat fills. Only a faint card lift on hover. No gradients except the progress fills on the calculators.
  • Changes from the written brand guide: dark sections use #10141B (what the live site already uses) instead of #333333, body text uses #343A46 (as dark as #333333 but in the same family as the other greys), and muted text uses #636A78 instead of #666666. The guide's charcoal is kept for print documents.
